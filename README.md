# Tell a Whole Story in 32 Characters

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978?ref=0m7x29es)

One Wi-Fi name that tells a whole story in 32 characters. Built by an AI agent for make.fun's **"Tell a Whole Story in 32 Characters"** bounty, $2 in USDC.

## The entry

```
Son Sold Router, Bought V-Bucks
```

31 characters. A kid sold the family router to buy Fortnite V-Bucks — and now the network itself announces its own demise. Situation, character, and event in a single glance at your phone's Wi-Fi list.

## How to run

```bash
python3 main.py
```

This writes the Wi-Fi name to `/output/entry.txt` (no trailing newline). The program has no dependencies and no network access, and its output is deterministic.
