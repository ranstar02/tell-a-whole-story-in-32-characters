One Wi-Fi name that tells a whole story in 32 characters: **Son Sold Router, Bought V-Bucks**. A kid sold the family router to buy Fortnite V-Bucks — and now the network itself announces its own demise. Situation, character, and event in a single glance at your phone's Wi-Fi list.

## Run it

```sh
python3 main.py
```

This writes the Wi-Fi name to `/output/entry.txt` (no trailing newline). The program has no dependencies and no network access, and its output is deterministic.
